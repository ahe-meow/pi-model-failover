# 04 UI

Mockups at `listRows = 7`, width 78. Vocabulary: `CONTEXT.md`. Components: `docs/design/03-components.md`. Every string below lives in `src/strings.ts`.

## Frame rules

```text
line 1        pi-model-failover                          [memory mode]   ← header (1)
line 2        [1 Model Manager] [2 Chains] [3 History] [4 Settings]      ← tab bar (1)
line 3        column header for the current list                          ← list header (1)
lines 4..10   7 data rows (listRows)                                      ← data
line 11       ─────────────────────────────────────────────              ← separator (1)
lines 12..13  key hints (1 or 2 lines)                                    ← footer
```

- Total height = 4 fixed lines + `listRows` + hint lines (1 or 2). Forms replace the list area with the same row budget and scroll fields when they exceed it.
- `listRows` is a Settings value, 5 to 20, default 7. Header, tab bar, list header, separator, and footer never count.
- Scrollbar: when rows exceed `listRows`, the last 2 columns of every data row hold one space followed by `█` (thumb) or `░` (track). Thumb length = `max(1, round(listRows * listRows / total))`, position proportional to the first visible index.
- `[memory mode]` appears in the header only while `SharedState.isMemoryMode()` is true.
- Selected row is prefixed with `▶`, others with a space. Marked rows (multi-select) show `[x]`, unmarked `[ ]`.
- Secrets render through `redactSecret`; no screen shows a raw key.

## Global keys (every tab, outside forms and overlays)

| Key | Action |
| --- | --- |
| `Tab` / `Shift+Tab` | next / previous tab |
| `1` `2` `3` `4` | jump to tab |
| `↑` `↓` `PgUp` `PgDn` `Home` `End` | move selection |
| `?` | toggle Help Overlay |
| `q` or `Esc` at top level | close `/failover` |
| `Esc` inside a sub-screen | back one level |

Inside the Help Overlay every key except `?` and `Esc` is swallowed.

### Target settings form

```text
  relay-4/gpt-4.1
▶ errorHandlingMode         smart                                ◂ ▸        
  maxRetries                5                                               
  reasoningEffort           inherit                              ◂ ▸        
  noProgressTimeoutSeconds  90                                              
  ttftTimeoutSeconds        60        (0 disables)                          
  Server Quality enabled   inherit                              ◂ ▸
  Server Quality TTFT      inherit                              ◂ ▸
  Server Quality no-progress inherit                              ◂ ▸
  modelParameters          {}
 ───────────────────────────────────────────────────────────────────────────
 Tab next  ◂ ▸ change  Enter save  Esc cancel  (inherit = use Settings default)
```

In every form, `Tab`/`Shift+Tab` and `↓`/`↑` move focus; `◂ ▸` steps a number field by 1 (clamped to its range) or cycles an option field. Each Target Server Quality row is tri-state: `inherit` removes that override, while `on` and `off` persist explicit booleans. When the effective master is off or both signals are off, the form shows: "Server Quality timers are disabled; requests may wait until the provider or Pi aborts." `modelParameters` is edited as a JSON object. The effective policy is snapshotted at request start.

The Settings tab edits the global `serverQuality` master, TTFT, and no-progress switches as `on`/`off`; it shows the same disabled-timer warning when the master is off or both signals are off. Target rows can override each field with `inherit`/`on`/`off`. `listRows` changes apply on the next render of every tab. The reset button opens a confirmation that states the count of affected Targets and appends one `manual` event per Target.

## Help Overlay (`?`)

Full-height overlay drawn over the current tab. Sections: Global, then the current tab's key table, then the current sub-screen's key table when one is open. Rendered with `HelpOverlay`; `?` or `Esc` closes.

## Confirmation screen (shared)

Every destructive action (delete provider, delete chain, remove first target, delete catalog models, reset all, sync attributes) uses one component: a title, up to 3 detail lines, and `[ Confirm ] [ Cancel ]` with `◂ ▸` and `Enter`; `Esc` cancels. Default focus is Cancel.
