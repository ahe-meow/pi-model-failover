# .scratch

Task tracking for this repo lives here as markdown. There are no GitHub issues.

- One directory per phase: `p0-shell/`, `p1-model-manager/`, `p2-engine/`, `p3-history/`, `p4-release/`.
- One file per task: `<phase>/issues/<NN>-<slug>.md`, numbered from `01`.
- Each task file starts with `Status:`, `Allowed edit surfaces:`, and `Acceptance:` lines, then the body. Handoff evidence appends under `## Comments`.
- The phase spec is its section in `docs/design/06-roadmap.md`; P0 tasks are spelled out in `docs/design/07-plan.md`.

Full conventions: `docs/agents/issue-tracker.md`.
